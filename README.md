# StepMed local product

Локальный расширенный прототип бота и операционного дэшборда по `StepMed_AUTOMATION_HANDOFF.md`.

## Структура репозитория

Лендинг размещается в `public/`, дэшборд доступен через `public/admin/`, API — в `public/api/`. Секреты не коммитятся: используйте `.env.example` как шаблон.

## Запуск

```bash
php -S 127.0.0.1:8080 -t public
```

Откройте http://127.0.0.1:8080/login.php. Для production задайте `ADMIN_PASSWORD` в `.env`; demo-пароля нет.

Схемы MySQL находятся в `migrations/001_schema.sql` и `migrations/002_school_core.sql`. Реальные платежи, Яндекс Календарь и Classario намеренно не подключены до утверждения открытых решений Q16–Q32.

## Безопасный деплой

Корень веб-сервера должен указывать на `public/`. Файл `.env` размещается уровнем выше `public/`; не публикуйте его и не передавайте секреты через Git. Включите HTTPS, задайте сложный `ADMIN_PASSWORD`, ограничьте доступ к `/admin` по аккаунтам и регулярно проверяйте журнал операций.

## Модули прототипа

Роли, Telegram-привязка, семьи, ученики, преподаватели, занятия, участия, счета, платежи, посещаемость, отчёты, начисления, исключения, аудит, outbox и JSON API. Все данные интерфейса пока демонстрационные; перед production нужны авторизация, MySQL-репозитории, CSRF, rate limits и идемпотентная обработка внешних событий.
