# StepMed local product

Локальный расширенный прототип бота и операционного дэшборда по StepMed handoff.

## Структура

- public/ — лендинг и публичные маршруты
- public/admin/ — дэшборд
- public/api/ — API и webhook
- app/ — бизнес-логика
- config/ — конфигурация
- migrations/ — SQL-миграции
- storage/ — логи и служебные данные

Реальные платежи, календарь и Classario подключаются после настройки доступов и утверждения правил Q16–Q32.
