# Безопасный деплой на iHor

1. Веб-корень сайта указывает только на `public/`; каталоги `app/`, `src/`, `migrations/` не должны быть доступны из браузера.
2. `.env` размещается рядом с `app/`, не коммитится и содержит только production-значения.
3. Обязательны HTTPS, сложный `ADMIN_PASSWORD` и запрет directory listing.
4. Вход выполняется через `/login.php`; выход — `/logout.php`.
5. API отвечает `401` без авторизации; ручное подтверждение платежа дополнительно проверяет роль, сумму и идентификатор операции.
6. Реальные T-Bank ключи пока не заполняются: подтверждение СБП выполняет Ксения вручную.
